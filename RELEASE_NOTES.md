# KhmerDub APK - Release Notes

## Version 1.0.0 (Initial Release)
- **Dedicated KhmerDub Native Android APK**: High-speed video and movie downloader for YouTube, Facebook, TikTok, WeTV, iQIYI, and generic web video streams.
- **Auto-Update Engine**: Built-in 1-click update checker pointing directly to `seangritthy/khmerdubapk`.
- **In-App Media Player & Web Sniffer**: Plays downloaded videos in-app and sniffs live streaming media links.
