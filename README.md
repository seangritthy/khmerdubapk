# KhmerDub APK 🇰🇭🎬

**KhmerDub APK** is a high-performance Android application built for downloading Khmer dubbed movies, series, and videos from YouTube, Facebook, TikTok, Instagram, Twitter/X, WeTV, iQIYI, and any web page.

## Key Features
- 🎬 **Multi-Platform Downloader**: High-speed extraction for YouTube, Facebook, TikTok, Instagram, Twitter/X, WeTV, and iQIYI.
- 🌐 **Web Sniffer Browser**: Automatically detects downloadable stream URLs (`.mp4`, `.m3u8`, `.webm`).
- ⚡ **Multi-Quality Support**: Download in 1080p Full HD, 720p HD, 480p SD, or extract MP3 audio.
- 📁 **Download Manager**: Background downloads, progress notifications, file management, and instant playback.
- 🎨 **Modern Dark Aesthetics**: Sleek dark mode UI with interactive visual cards and quick clipboard auto-paste.

## Building from Source
Run the automated build script:
```bash
./build_apk.sh
```
The compiled signed APK will be output to `khmerdubapk.apk`.
